PUBLICACION DEL DASHBOARD EN STREAMLIT COMMUNITY CLOUD

1. Crear un repositorio publico en GitHub, por ejemplo: banco-peru-examen-final.
2. Subir TODO el contenido de esta carpeta dashboard/ al repositorio.
3. Verificar que esten: app.py, requirements.txt, dashboard_data.csv,
   comparacion_modelos.csv, perfil_clusters.csv y fairness_departamento.csv.
4. Ingresar a Streamlit Community Cloud con la cuenta de GitHub.
5. Elegir "Create app" / "Deploy an app".
6. Seleccionar el repositorio, rama main y archivo app.py.
7. Desplegar y esperar a que termine la instalacion.
8. Abrir la URL publica desde una ventana de incognito para comprobar acceso.
9. Copiar la URL en LINK_PUBLICO_DASHBOARD.txt y reemplazar el texto
   PENDIENTE_PUBLICAR dentro del informe antes de entregar.
